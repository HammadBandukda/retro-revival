# ChatGPT workspace

ChatGPT-specific working guidance and generated deliverables for this repository. This folder sits alongside `.claude/`; it does not replace Claude's skills or the shared project sources.

## Start here

1. Read the repository `README.md` and `CLAUDE.md` for shared facts, project layout, and client rules.
2. Follow [WORKFLOW.md](WORKFLOW.md) for ChatGPT-specific source, production, and verification practices.
3. Use project prompts and data under `projects/<workstream>/` as the task brief and source material.
4. Archive finished ChatGPT outputs under [generated/](generated/README.md).

Keep facts in their existing source docs under `docs/`, `assets/`, and the matching `projects/` folder. Keep prompts with their workstream. Treat generated files as dated deliverable snapshots and record prompt, inputs, format, and verification in each package README.
