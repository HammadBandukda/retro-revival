# Website Scope (Draft)

**Status:** pending client confirmation. Do not build until the deliverable is confirmed (see [open questions](../client/open-questions.md)).

## Goal

In 30 seconds, an overseas buyer should see a legit exporter instead of a random Instagram account. The site should turn visits into WhatsApp and LINE inquiries. **No checkout in v1.**

## Pages

| Page | Content |
| :- | :- |
| **Home** | Hero with the warehouse or container video. Value proposition ("Curated vintage bales, ready to ship worldwide from Bangkok"). Trust strip (Co. Ltd., Google rating, countries shipped to). Current stock highlight. WhatsApp call to action |
| **Catalog / Bales** | Categories: Jackets, Denim, Workwear (Carhartt and Dickies), T-shirts, Sweatshirts, Dresses, Sportswear, Leather, Caps. Each bale shows its name, piece count or weight, photos or video, a "from" price or "price on request," and an inquiry button |
| **Weekly Stock List** | The current list, downloadable as an image or PDF |
| **How It Works** | Inquiry → photos or video of the bale → payment → packing → shipping. Minimum order, payment methods, lead times |
| **Shipping** | Countries, sea vs. air, container loads, documentation |
| **Visit the Warehouse** | Map, address, the "20 min from Suvarnabhumi" pitch, the location reel, hours |
| **About** | Story, team, warehouse photos |
| **Contact** | Form plus WhatsApp, LINE, and phone |

## Requirements

- **Bilingual EN/TH**, for the two audiences (see [reel analysis](../research/reel-analysis.md#insight-two-audiences-one-feed))
- Mobile-first, because buyers arrive from IG and WhatsApp
- A floating WhatsApp button on every page
- A CMS-driven catalog and stock list, so the client can update them weekly without a developer
- Fast loading for video and images (heavy media, international visitors)
- **SEO targets:** "vintage clothing wholesale Thailand," "vintage bales Bangkok," "Carhartt bales wholesale," and their Thai equivalents

## Platform

Hammad's default is **Webflow** (CMS + Localization). Confirm before scaffolding any code-based alternative.
